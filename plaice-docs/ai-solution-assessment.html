AI Solution Assessment — Plaice Maturity Explorer

Prepared with reference to the Government of Newfoundland and Labrador OCIO Responsible Use of Artificial Intelligence Technology policy (gov.nl.ca/exec/ocio/ai-policy)

Prepared by: Vibhu Sharma (vibhus@mun.ca)Date: September 2026Status: Personal portfolio project — not a government submission

Purpose & Scope

A demonstration decision-support tool that predicts the probability of sexual maturity at age for female American plaice cohorts (NAFO Divisions 3L, 3N, 3O), from the fitted model in Zheng, Cheung, Sharma, Thorson & Cadigan (2026), arXiv:2608.31133. Built to show a responsible-AI-aligned deployment pattern for a published scientific model — plumber API, web front end, and an LLM layer for plain-language interpretation. This is an educational/portfolio artifact, not an operational stock-assessment or regulatory tool, and is not deployed for public-facing government use.

Data Sources & Governance

Training dataDFO/NAFO fisheries survey data underlying the published paper — a public academic dataset, not government-confidential or personal information. No Cabinet records or ATIPPA-scoped personal information are involved; a Privacy Impact Assessment is not applicable.
Raw data handlingThe raw survey extract is excluded from the public code repository (.gitignore) pending explicit confirmation of redistribution terms — the deployed API serves only a precomputed prediction grid, not the underlying records.

System Architecture

R/TMB neural-network mixed-effects model (fitted offline) → static prediction grid, precomputed with delta-method confidence intervals → Plumber (R) API → Next.js front end → Azure AI Foundry (gpt-4.1-mini) for a grounded chat layer that interprets results in plain language.

Alignment with the Five Guiding Principles

Transparent & Explainable — Every page shows a Model Card disclosing training-data scope, known limitations, and data provenance. The chat layer is instructed to cite the confidence interval alongside any probability it states.

Fair & Ethical — The model uses only age and birth cohort of a single fish stock/sex/region; it involves no personal or demographic data about individuals, and its scope is explicitly disclosed to prevent misapplication to other stocks or regions.

Private & Secure — No personal or confidential information is processed or stored. API keys are kept server-side, excluded from source control, and no user conversation data is persisted beyond the browser session.

Accountable & Responsible — Single named owner (above) accountable for the tool. Outputs are explicitly scoped as exploratory/educational, not a basis for operational or regulatory decisions.

Human Oversight — Predictions in statistically non-identifiable regions (e.g., cohorts at the edge of the training window) are algorithmically forced to a maximally uncertain [0%, 100%] interval and flagged, rather than left to look falsely precise. Any AI-generated interpretive text is presented as a gloss to be verified against the chart, not an authoritative source — consistent with the policy's requirement that AI-generated content be validated by a person before use.

Performance Monitoring

Offline: the published model's held-out test performance (binary cross-entropy 0.249) is comparable to a standard GLMM baseline (0.250), reported in the source paper. At runtime: the app computes a live uncertainty flag on every query — it auto-highlights when the displayed 95% CI exceeds a fixed width threshold or falls in a non-identifiable region — giving an always-on signal rather than relying solely on a one-time offline metric.

Hallucination Risk (LLM Layer)

The chat layer's system prompt restricts it to numeric claims present in the currently displayed data (it is instructed to say so and ask the user to adjust the chart controls, rather than estimate, when asked about a cohort/age not shown), and mandates stating the confidence interval — and explicitly flagging non-identifiable ones as unreliable — alongside any probability it cites. Residual risk: free-text explanatory content (e.g., biological reasoning about why a cohort matures later) is model-generated and not independently fact-checked, and should be read as a plain-language gloss, not a citable scientific claim.

Approval Scope

Personal/internal demonstration only. Any use beyond this scope — in particular any government or public-facing operational use — would require a formal AI Assessment Process (AIA) submission and Deputy Minister approval under the OCIO policy, which this project has not sought and does not require at its current scope.
